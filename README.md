# punto-design

Fixed-price design &amp; social media services.

Landing page for **Punto**, a studio selling design and social-media work at a
fixed price — one package, one number, no surprises on the invoice.

## Concept

The name *is* the idea: *punto* is Italian for "full stop." The prices are
final, so the whole page is punctuated by a single cobalt dot — the hero, the
section dividers, and the end of every claim.

## Files

- `index.html` — the page (Italian copy).
- `styles.css` — design tokens and layout. Palette: warm paper `#FBFAF6`,
  ink `#16151A`, cobalt `#1E2AEA`, periwinkle `#E7E7FB`, amber `#FFC24B`.
  Type: Bricolage Grotesque (display) · Instrument Sans (body) · DM Mono (prices).
- `script.js` — footer year + single-open FAQ accordion.

## View it

Open `index.html` in a browser, or serve the folder:

```
python3 -m http.server
```

Then visit http://localhost:8000. No build step; fonts load from Google Fonts.
